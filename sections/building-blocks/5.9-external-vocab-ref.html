[H5-9] External Vocabulary Referencing

It is essential for FDOs that existing vocabularies (for example, schema.org) can be reused in FDO records. To prevent that each vocabulary term must be wrapped into its own FDO attribute definition, Handle-based FDOs adapt the external vocabulary referencing mechanism (Implementation-specific rule). If terms from a vocabulary should be used in the FDO record, the FDO record has to import this vocabulary. This is done by referencing from the FDO record to an FDO that describes this vocabulary. After importing the vocabulary, any term from it can be used within the FDO record.

An FDO that describes an external vocabulary (vocabulary FDO) follows the external vocabulary profile 21.T11969/VocabularyDef. Its properties are listed in Table 6 below.

Table 6: The list of attribute definitions which MUST be used when registering a new FDO that describes a vocabulary. This table does not include all information about the attribute definitions. For more details, please resolve the attribute definition PIDs via the Handle System.
PID of the attribute definition Attribute value Cardinality of the attribute
21.T11969/Type The string Vocabulary. Additional types may be added, if applicable. 1..*
21.T11969/Profile The string 21.T11969/VocabularyDef. Additional profiles may be added, if applicable. 1..*
21.T11969/Data At least the string 21.T11969/DownloadURL. Other data references may be added, if applicable. 1..*
21.T11969/DownloadURL URL to download the vocabulary. 1..*
21.T11969/Name Name(s) of the vocabulary. 1..*
21.T11969/Description Description(s) of the vocabulary. 0..*
21.T11969/LandingPage Link to human-readable landing page of the vocabulary. 0..1
21.T11969/VocabularyPrefix Unique prefix(es) of vocabulary terms in an FDO record. 1..*
21.T11969/SPARQL_Check SPARQL query for validating vocabulary terms in the FDO record 0..1
21.T11969/Contact Contact information for the vocabulary. 1..*

External vocabulary referencing is a special case of profile referencing, applied to the attribute definition 21.T11969/ImportVocabulary. Hence, the FDO record of 21.T11969/ImportVocabulary is constructed the same way as described in [H5-7]. Hereby, the profile that is referenced by 21.T11969/ImportVocabulary is 21.T11969/VocabularyDef.

Instantiation of External Vocabulary Attributes in the Record: To use external vocabulary terms in the FDO record, the record MUST contain
  1. the attribute (21.T11969/ImportVocabulary,[reference to a vocabulary FDO])
  2. one or several attributes representing vocabulary terms from the same vocabulary. Those attributes must have as their first value the vocabulary term, starting with a valid prefix of this vocabulary as listed in the vocabulary FDO. The second value must instantiate the vocabulary term.

Validation Rules: To validate an FDO that contains the attribute 21.T11969/ImportVocabulary, it is checked that the attribute value of 21.T11969/ImportVocabulary is a reference to a vocabulary FDO. A FDO validator could now optionally proceed to validate the vocabulary terms according to the SPARQL query, if it is given in the vocabulary FDO.

Figure 5 illustrates how schema.org terms can be used in an FDO record by applying external vocabulary referencing. The example FDO 21.123/456 contains the attribute (21.T11969/ImportVocabulary, 21.abc/SchemaOrg), indicating that it uses vocabulary from schema.org. The vocabulary FDO 21.abc/SchemaOrg specifies the vocabulary prefixes schema: and https://schema.org/. Any other attribute that starts with either of these prefixes would be recognized and interpreted as a schema.org term (blue attributes).
