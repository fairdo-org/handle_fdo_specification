[H5-5] Composition of Attribute Definitions

There are two ways how to encode the composition of attribute definitions in Handle-based attribute definitions:

[H5-5a] Compositions implemented by JSON Schemas:

The FDO record of the attribute definition A contains a JSON schema which encodes a composition of attributes A1,...,An. In detail, the attribute 21.T11969/Data applies attribute referencing to point to the attribute 21.T11969/JsonSchema, which has as its value a JSON schema.

The JSON schema implements a composition as an object with properties. Each property corresponds to one of the attribute definitions A1, A2, ... If the attribute definition Ai has a cardinality larger than 1, then the property is an array with the respective cardinality. The cardinality of Ai can also be overwritten in the composition (only narrowing down the cardinality is possible, e.g. from 1..10 to 2..5).

The resulting composition `A` is a new attribute definition that has its own cardinality, which gives information on how often `A` can and must be repeated in an FDO record.

The following FDO record gives the attribute definition of an author, which is a composition of a first name and a last name.

21.T11969/Type FDO_Attribute
21.T11969/Profile 21.T11969/AttributeDef
21.T11969/Name author
21.T11969/Description An author is a composition of a first name and a last name..
21.T11969/Cardinality 1
21.T11969/Data 21.T11969/JsonSchema

Attribute FDO record (fictionary PID: 21.T11969/Author)
The full validation schema for the Author attribute can be found here. The validation schema is constructed as follows:
  • line 3: identifier of the attribute definition
  • line 4: name of the attribute
  • line 5: description of the attribute
  • line 7: the plain syntax (as given in lines 40, 80) is wrapped into the handle record syntax
  • lines 23, 82: The Author is given a cardinality for validation in the Handle record. An Author can appear between 1-n times in the handle record.
  • lines 41, 81: reference to the subschema composing the first name and the last name.
    • lines 8-18: inline attribute definition of the first name, including narrowing down its cardinality from 1-5 (in the syntax def of 21.T11969/Name) to 0-3
    • lines 19-28: inline attribute definition of the last name, including narrowing down its cardinality from 1-5 (in the syntax definition of 21.T11969/Name) to 1-3

This schema validates any handle record that has between 1-n handle values representing a Author, for example record 1 and record 2.

A composition of attributes is implemented by setting two attributes in the FDO record:
  1. (21.T11969/ValidationMechanism, InlineCombination)
  2. (21.T11969/DataType, [reference to attribute definition]), repeated multiple times.
The following three attributes define a composition of a string and an integer.
  1. (21.T11969/ValidationMechanism, Composition),
  2. (21.T11969/DataType, 21.T11969/3df63b7acb0522da685d),
  3. (21.T11969/DataType, 21.T11969/9edcffff4461c9083fbf),
